# ShopSphere Full-Stack E-Commerce Application

ShopSphere is located in the `./shopsphere` directory.

Please refer to [`./shopsphere/README.md`](./shopsphere/README.md) for full project documentation, architecture specifications, API routes, database schemas, and setup instructions.

### Quick Start
- **Backend**: `cd shopsphere/backend && mvn spring-boot:run`
- **Frontend**: `cd shopsphere/frontend && npm run dev`
- **Default Admin**: `admin@shopsphere.com` / `Admin@123`
- **Default Customer**: `customer@shopsphere.com` / `Customer@123`
